# Intelligent Knowledge Assistant

A local-first **RAG + agentic** assistant answering questions over a curated
corpus on RAG architecture, vector databases, and agentic AI frameworks.

Try:
- *What chunking strategies are described for RAG?* (simple RAG)
- *Compare FAISS, pgvector, and Chroma for a production RAG system.* (agentic)
- *What is Best Buy's return policy?* (out-of-scope → honest abstention)
